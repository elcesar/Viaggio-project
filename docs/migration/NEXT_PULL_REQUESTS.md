# Roadmap de Pull Requests

El plan operativo, estados, criterios de revisión por César y gates de producción están en [`docs/operations/PRODUCTION_PR_RELEASE_PLAN.md`](../operations/PRODUCTION_PR_RELEASE_PLAN.md). Los PR 01-04 ya están abiertos; las filas siguientes de ese documento son propuestas, no cambios ya implementados.

1. Fundación React, layout y Home.
2. Gira, familias, estudiantes e importación CSV.
3. Presupuesto, cuotas y libro financiero.
4. Documentos, autorizaciones y almacenamiento.
5. Comunicaciones, calendario y votaciones.
6. Eventos y asistencia.
7. Agencias y verificación.
8. Paquetes, buscador y comparación.
9. Solicitudes, propuestas y mensajería.
10. Cognito, sesiones y autorización.
11. API modular, PostgreSQL y auditoría.
12. S3 documental, SQS y workers.
13. API Gateway, WAF y observabilidad.
14. EKS, ECR, Terraform y GitOps.
15. S3 web, CloudFront y staging.
16. Seguridad, respaldo, rendimiento y piloto.
