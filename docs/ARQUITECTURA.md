# Arquitectura

## Etapa inicial

La primera versión será una demo estática:

- HTML
- CSS
- JavaScript
- Sin backend
- Sin base de datos

## Evolución

La arquitectura definitiva se definirá una vez validadas las funcionalidades mediante la demo.

Estructura futura posible:

```text
demo/
frontend/
backend/
docs/
```

Esta estructura es referencial y no implica todavía una decisión tecnológica para producción.
