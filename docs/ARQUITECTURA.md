# Arquitectura

## Contexto

Viaggio se proyecta como un producto comercial reutilizable para distintos colegios, generaciones y comunidades. La arquitectura definitiva deberá considerar este alcance y no quedar acoplada al caso de referencia de la Scuola Italiana.

## Etapa inicial

La primera versión será una demo estática:

- HTML
- CSS
- JavaScript
- Sin backend
- Sin base de datos

Su objetivo es validar la propuesta de producto, experiencia y funcionalidades.

## Evolución

Una vez validadas las funcionalidades, se definirá la arquitectura de la aplicación comercial. Esta deberá permitir progresivamente múltiples organizaciones, generaciones, usuarios, roles y configuraciones.

Estructura futura posible:

```text
demo/
frontend/
backend/
docs/
```

Esta estructura es referencial y no implica todavía una decisión tecnológica para producción.
