# Modelo de Datos

Documento reservado para definir las entidades y relaciones del producto **Viaggio**.

El modelo deberá permitir que la plataforma opere con múltiples colegios, generaciones y grupos de viaje, evitando incorporar como reglas universales aquellas que pertenezcan únicamente al caso de referencia inicial.

## Entidades preliminares

- Colegio
- Generación / Grupo de viaje
- Alumno
- Familia / Apoderado
- Comisión
- Actividad / Evento
- Turno
- Participación
- Asistencia
- Punto
- Movimiento financiero
- Proveedor / Aliado
- Viaje

## Caso de referencia

La Generazione 2028 de la Scuola Italiana Vittorio Montiglio servirá para validar el modelo con información y procesos reales.

El modelo definitivo se definirá después de validar los requerimientos funcionales y distinguir entre reglas generales del producto y configuraciones particulares de cada comunidad.
