# Demo de Viaggio

Directorio destinado al prototipo navegable del producto **Viaggio**.

La demo permite visualizar y validar la propuesta comercial, experiencia y funcionalidades antes de desarrollar la aplicación definitiva.

El caso de la Generazione 2028 de la Scuola Italiana Vittorio Montiglio puede utilizarse como referencia para representar escenarios reales, sin limitar el producto a ese colegio o generación.

La página principal del prototipo se mantendrá como `index.html`.
