# Viaggio G'28

Proyecto de apoyo digital para **Viaggio in Italia – Generazione 2028**.

## Objetivo

Centralizar progresivamente las herramientas digitales necesarias para apoyar la organización de actividades, turnos, asistencia, puntos y demás procesos asociados a Viaggio G'28.

## Etapa actual

El proyecto se encuentra en su etapa inicial de definición. La primera implementación será una demo estática en HTML/CSS/JavaScript destinada a visualizar y validar funcionalidades antes de definir la arquitectura definitiva.

## Estructura

- `docs/`: documentación funcional y técnica del proyecto.
- `demo/`: espacio reservado para el futuro prototipo HTML.
